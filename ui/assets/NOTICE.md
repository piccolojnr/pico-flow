# Bundled UI assets

These assets are served locally by Tauri; opening the UI does not request them from a CDN.

- `satoshi-400.woff2`, `satoshi-500.woff2`, `satoshi-700.woff2`: Satoshi, distributed by Indian Type Foundry through Fontshare. Downloaded from the font files referenced by https://api.fontshare.com/v2/css?f[]=satoshi@400,500,700&display=swap. Typeface: https://www.fontshare.com/fonts/satoshi.
